# Угадай число

Домашнее задание по SOLID. Программа загадывает случайное число, игрок вводит варианты и получает подсказки: загаданное число больше или меньше. Если число угадано или попытки закончились, игра завершается.

## Запуск и настройки

Нужен .NET SDK 9.0. Из папки проекта:

```powershell
 dotnet run --project src/GuessNumber -c Release
```

Диапазон и количество попыток задаются в `src/GuessNumber/settings.json`:

```json
{
  "MinNumber": 1,
  "MaxNumber": 100,
  "MaxAttempts": 7
}
```

Границы входят в диапазон. При вводе текста или числа вне диапазона программа просит повторить ввод, попытка не расходуется.

## Что сделано по SOLID

**S — единственная ответственность.** `GuessNumberGame` управляет игрой, `RandomSecretNumberGenerator` генерирует число, `JsonGameSettingsProvider` читает настройки. `GameSettings` хранит и проверяет параметры. Ввод и вывод находятся в отдельных классах.

**O — открытость/закрытость.** Логика игры работает через интерфейсы. Другой способ генерации числа или ввода и вывода можно добавить отдельной реализацией интерфейса, не меняя `GuessNumberGame`. Подключение реализаций находится в `Program.cs`.

**L — подстановка Барбары Лисков.** Реализации соблюдают контракты интерфейсов. `RandomSecretNumberGenerator` возвращает число в переданном диапазоне, включая границы, и допускает диапазон из одного числа. `ConsoleGameInput` возвращает строку или `null` при завершении ввода, что игра обрабатывает. Код игры использует только эти контракты и не проверяет конкретные типы зависимостей.

**I — разделение интерфейсов.** Созданы небольшие интерфейсы `IGameInput`, `IGameOutput`, `ISecretNumberGenerator` и `IGameSettingsProvider`. Ввод отделён от вывода, поэтому классы не реализуют методы, которые им не нужны.

**D — инверсия зависимостей.** `GuessNumberGame` получает генератор, ввод и вывод через конструктор и зависит от интерфейсов. Конкретные классы создаются в `Program.cs`. Сама игра не обращается к консоли, файлам или `Random` напрямую.
